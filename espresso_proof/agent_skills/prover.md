# Skill: prover

Develop the selected route into a proof sketch or repair attempt.

- Use only the current run's checked examples, source statuses, reviewer
  objections, and budget.
- Respect candidate sources as candidate; do not cite them as support.
- Stop at missing sources, missing hypotheses, or insufficient detail instead
  of filling gaps with prose.
- Use safe language: proof sketch, proof candidate, conditional argument, repair
  attempt.
