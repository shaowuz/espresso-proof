# Skill: reference-matcher

Check whether a specific source can support a specific proof step.

- Require attribution, exact locator, and hypothesis match.
- Check base field, characteristic, smoothness, properness/projectivity,
  flatness, singularities, coefficients, genericity, and category.
- Do not turn very general into all, smooth into singular, or local into global.
- If the match is uncertain, say which condition is missing.
