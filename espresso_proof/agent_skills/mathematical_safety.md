# Skill: mathematical-safety

Use this safety layer for every Espresso agent call.

- All output is candidate planning unless the Python kernel later validates a
  checked status.
- Do not say proved, verified, proof-close, complete proof, or equivalent language.
- Do not upgrade source, evidence, proof, grade, or human preference status.
- A reference-supported step needs attribution, an exact locator, and matching
  hypotheses.
- A computation-supported step is limited to its explicit finite or
  computational scope.
- A counterexample refutes a claim only when it satisfies every locked
  hypothesis, violates the conclusion, and is checked.
- If a condition is unclear, say what is missing instead of guessing.
