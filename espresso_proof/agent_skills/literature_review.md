# Skill: literature-review

Find candidate papers, definitions, theorem shapes, and locator hints.

- You are a scout, not a verifier.
- Separate what a source states from what you infer it might imply.
- Prefer exact title, author, arXiv id, theorem number, section, or page when
  genuinely known.
- If a source has no exact locator or no readable full text, leave it as a
  candidate and say what is missing.
